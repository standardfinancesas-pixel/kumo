# @kumo/shared

Capa compartida por todas las superficies de Kumo (landing, admin, webapp, mobile).

- `src/tokens.ts` — tokens de diseño: colores, tipografías, radios, sombras.
- `src/types.ts` — tipos del dominio (Plan, Pet, Reimbursement, Provider, …).
- `src/data/` — datos de ejemplo del prototipo (fuente de verdad para el seed de Supabase).
- `src/supabase.ts` — factory del cliente de Supabase (browser + server).
- `assets/` — imágenes (.webp/.png) y tipografía Baloo 2 (.woff2) extraídas del prototipo.
